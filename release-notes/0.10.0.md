## Lumora 0.10.0 — Picture in Picture

### New
- **Picture in Picture** (View › Picture in Picture, ⌥⌘P, or the ••• and right-click menus). The video moves into the macOS floating PiP window, which stays above other apps and on every Space.
  - Play/pause and ±15 s skip work from the PiP window, and its progress bar follows playback, pauses and speed changes.
  - The main window shows "Playing in Picture in Picture" with a Return to Window button. Closing PiP puts the video back in the window.
  - Subtitles appear in PiP too.
  - It needs the Metal renderer, which is the default.

### Good to know
- The PiP timeline can't be dragged: macOS only allows that for apps using Apple's own player. Use the ±15 s buttons, or Lumora's mini player (⌥⌘M), which also floats and has a draggable seek bar.
- While PiP is open, Lumora draws the small PiP picture itself, so CPU use is a little higher than in the window (memory is lower).

### Install / update
Existing installs are offered this update automatically (Lumora → Check for Updates…).
New installs: download `Lumora-0.10.0.dmg` and drag Lumora into Applications. First launch only: **System Settings → Privacy & Security → Open Anyway** (not notarized yet).
