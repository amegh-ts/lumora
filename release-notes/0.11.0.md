## Lumora 0.11.0 — crash reports

### New
- **Crash reports you control.** If Lumora quits unexpectedly, the next launch offers to report it:
  - **Send Report…** opens a pre-filled issue on GitHub that you can read before submitting. It contains the Lumora and macOS versions, your Mac model, the renderer, the crash reason and where in the code it happened.
  - **Copy Report** puts the same text on the clipboard, for anyone without a GitHub account.
  - **Don't Send**, or "Don't ask about crashes again" (also in Settings › Advanced).
  - File names, video titles, links and folder paths are removed before you see the report, and nothing is sent unless you submit it. Lumora uses the crash log macOS already keeps, so there is no tracking library and no server.

### Maintenance
- The build and release workflows use the current GitHub Actions versions (Node 24), removing the deprecation warning.

### Install / update
Existing installs are offered this update automatically (Lumora → Check for Updates…).
New installs: download `Lumora-0.11.0.dmg` and drag Lumora into Applications. First launch only: **System Settings → Privacy & Security → Open Anyway** (not notarized yet).
