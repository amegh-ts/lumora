## Lumora 0.8.0 — subtitle style, playback extras, playlists and a compact mini player

### Subtitles
- **Choose how subtitles look** (Settings › Subtitles): font, colour, background (outline, drop shadow or dark box) and how high they sit above the bottom.
- **Preferred languages**: the subtitle track (Settings › Subtitles) and audio track (Settings › Audio) in your languages are picked automatically when a file opens, e.g. `en, es`.

### Playback
- **Volume boost** up to 200% for quiet files (Settings › Audio, the Audio menu or the control bar's Audio button).
- **Output device**: choose where sound plays (AirPods, speakers, display). If the saved device is unplugged, Lumora uses the system default.
- **Video menu**:
  - Aspect Ratio (16:9, 4:3, 2.35:1, 1.85:1, 1:1).
  - Crop presets to remove black bars.
  - Deinterlace (Off / Automatic / On) for old TV recordings.

### Playlists
- **.m3u, .m3u8 and .pls files** open as separate playlist items with their titles. HLS stream playlists still play as one stream.
- **YouTube playlist links** load every video (up to 500) as separate items, starting at the video you opened.

### Mini player
- **Compact controls** appear only while the pointer is over it: close, back to the full window, ±10 s, play/pause and a thin seek bar.
- **Snaps to the nearest screen corner** after you drag it.
- **Smaller**: it opens at 360 pt wide, can shrink to 200 pt and keeps the video's shape.

### Security
- Playlist files can only list local files and normal network links. Entries that would make mpv generate or read other data (lavfi, edl, memory, av) are ignored.
- Lumora now checks every address before playing it, however it was opened: only local files and normal network links (http, https, rtsp, rtmp, mms, ftp, smb, udp, rtp, srt) are accepted.

### Install / update
Existing installs are offered this update automatically (Lumora → Check for Updates…).
New installs: download `Lumora-0.8.0.dmg` and drag Lumora into Applications. First launch only: **System Settings → Privacy & Security → Open Anyway** (not notarized yet).
