## Lumora 0.7.0 — Media Info, window sizing and better audio and stream views

### New
- **Separate Audio and Subtitles buttons** in the control bar, each with its own menu.
  - Audio: track, audio delay, equalizer.
  - Subtitles: track, add file, search online, subtitle delay.
  - The right-click menu has the same two submenus.
- **Media Info** (Window › Media Info, ⌘I): codec, resolution, HDR, bitrate, frame rate, hardware decoding, dropped frames and audio details, updated every second.
  - For online videos it also shows how much is buffered and the download speed.
- **Go to Time** (Playback › Go to Time…, ⌘J): type `1:23:45`, `12:30` or `90`.
- **Window sizes**: View › Half Size (⌘0), Actual Size (⌘1), Double Size (⌘2) and Fit to Screen (⌘3).
- **The window keeps the video's shape** while you resize it in Fit mode, so no black bars appear.
- **New setting** (Settings › General › Window): resize the window to the video for every file, the first file only, or never.
- **Buffer bar**: online videos show the already-downloaded part on the timeline.
- **LIVE badge**: live streams and internet radio show "● LIVE" instead of a seek bar.
- **Audio-only files** show the title, artist and album instead of a black screen; radio stations show the station name.

### Fixes
- YouTube videos no longer list about 17 audio tracks; there is one per language, and the best format is picked automatically.
- The subtitle delay in the menu shows the current video's delay, not the default from Settings.
- A newly opened video could size the window from the previous video's dimensions.

### Install / update
Existing installs are offered this update automatically (Lumora → Check for Updates…).
New installs: download `Lumora-0.7.0.dmg` and drag Lumora into Applications. First launch only: **System Settings → Privacy & Security → Open Anyway** (not notarized yet).
