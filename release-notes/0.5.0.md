## Lumora 0.5.0 — new Settings and menu bar

### Highlights
- **Redesigned Settings** (Lumora → Settings…, ⌘,): a proper Mac preferences window with General, Video, Audio, Subtitles, Network and Advanced panes, grouped like System Settings.
  - **Audio**: a real 10-band equalizer with presets (Bass Boost, Vocal, Rock, Loudness, Night…).
  - **Video**: renderer, hardware decoding, brightness/contrast/saturation with reset.
  - **Subtitles**: size and delay, OpenSubtitles with a "Get a Free API Key" button.
  - **Network**: yt-dlp and ffmpeg paths with a Choose… button and found/not-found status.
  - **Advanced**: open the screenshots, logs and library folders, view licenses, reset all settings.
- **API key in the Keychain**: your OpenSubtitles key is now stored in the macOS Keychain instead of a settings file, moved over automatically.
- **New menu bar**: Playback, Audio, Subtitles and Video menus with icons; live submenus for audio and subtitle tracks, chapters, bookmarks, speed, video size and repeat; File → Open Recent.
- **Shortcuts shown in the menus** (Space, arrows, letters). They work only while a player window is focused, so typing in text fields is never interrupted.

- **Liquid Glass control bar** on macOS 26 and later (frosted blur on older systems). Only the control bar uses glass; on-screen messages, seek preview and playlist use a light tint, so the effect costs as little as possible.
- **Lighter in the background**: when the player window is minimized, on another Space or fully covered, Lumora stops drawing video; after 5 seconds it turns the video output off entirely so its GPU memory is freed (audio keeps playing) and brings it back instantly when you return. In testing a minimized 720p video dropped from 266 MB to 196 MB and from 14% to 4% CPU.
- **Lighter while playing**: 720p now uses about 199 MB (was 254 MB) and 4K about 350 MB (was ~380 MB), at or below Elmedia (203 MB / 365 MB) with roughly half its CPU. Controls and the timeline stop updating while hidden, library and settings are saved in the background, mpv's unused built-in scripts are off, and shaders are cached between launches.

### Online videos (YouTube and other sites)
- **Quality menu**: Video › Quality (and Quality in the control bar's ••• menu) lists every resolution the video offers, e.g. 2160p60, 1440p60, 1080p60, with codec and bitrate. Switching keeps your place and takes under a second; there's no reload.
- **Starting quality setting** (Settings › Video › Online Videos). Auto, the default, picks the highest quality your display can show, e.g. 1440p on a MacBook Air. Choose Best available or a fixed resolution to change it.
- **No more buffering on ±10 s jumps**: YouTube slows down a single long download (about 700 KB/s in testing, below what 4K needs), so Lumora now downloads in 10 MB pieces over one connection, like yt-dlp does. It keeps up to 2 minutes ahead and about 48 MB behind in memory. In testing, 8 arrow-key jumps in a row played without buffering once the first few seconds had loaded.
- **Faster opening**: website links go straight to yt-dlp instead of first failing a direct-play attempt, and direct media links (.mp4, .m3u8, .mkv…) skip yt-dlp entirely. Most of the remaining 3 s is yt-dlp contacting YouTube. While that happens, the player now says "Fetching video from youtube.com…".
- Macs without an AV1 hardware decoder (M1, M2) get VP9/H.264 streams instead of software-decoded AV1.

### Fixes from a full product, QA and performance audit
- Controls no longer pop up every 10 seconds while watching (each progress save used to bring them back).
- Choosing an audio track, A-B loop or rotation in one file no longer carries over to the next (which could make the next file silent).
- Subtitle and audio delay now apply to the current file only; Settings holds the default for new files. Audio delay is new in the Audio menu (- / ⇧=).
- Volume changes in one window no longer change other windows; downloaded subtitles go only to the window you're using.
- A file that can't be played now says why (missing, damaged, unsupported, network) and the playlist skips to the next item.
- Missing recent files show "couldn't be found" with an option to remove them, instead of doing nothing.
- Resume works again for films you finished once; progress is saved when you switch files or stop.
- After the end, skipping back and pressing Play no longer restarts from 0:00.
- Repeat One works with Autoplay off; Shuffle stops after every item played when Repeat is off, and Previous goes back through what you watched.
- Portrait videos no longer open a window taller than the screen.
- Reopening a file already in the playlist selects it instead of adding a duplicate; dropping a large folder no longer freezes the app.
- The playlist "−" button no longer removes the playing item just because it was highlighted.
- Slow streams no longer fall back to OpenGL by mistake; Metal failure is detected from mpv's own error.
- Library and settings files can't be wiped by a damaged file or a future format change; unreadable files are kept as backups.
- Closing the window that owns media keys hands them to another playing window.
- OpenSubtitles results are read in the API's documented format.
- Converter: no double runs, Convert becomes Cancel while running, ffmpeg stops when Lumora quits, and "Replace" in the save panel is honoured.
- Seek-bar previews are lighter (debounced, cheaper decoding, failures remembered, refreshed when a file changes).
- Menus no longer rebuild on every key press; repeated on-screen messages update in place.
- Accessibility: VoiceOver can seek with the timeline, hears on-screen messages and gets correct button names; controls stay visible with VoiceOver on; Reduce Motion is respected; recent items work from the keyboard.
- Previous/Next are hidden when there's only one item; the remaining/total time choice is remembered; chapter marks are visible.
- Settings: "Network" is now "Tools"; Open URL explains invalid links; the keyboard shortcuts help and docs match the app.

- Equalizer sliders no longer change unrelated settings.
- Entering full screen from the mini player restores the normal window first.
- Duplicate items in the Edit and View menus removed.

### Install / update
Existing installs are offered this update automatically (Lumora → Check for Updates…).
New installs: download `Lumora-0.5.0.dmg` and drag Lumora into Applications. First launch only: **System Settings → Privacy & Security → Open Anyway** (not notarized yet).
