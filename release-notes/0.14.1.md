## Lumora 0.14.1 — fixes and safety

### Fixed
- **Live TV lists and favourites could disappear** when two player windows were open and one closed its channel panel. The lists are now kept while any window uses them, and an unreadable channel file is set aside instead of wiping the saved lists.
- **A rare crash when closing a window** while a video was still opening or Picture in Picture was on.
- **"Metal unavailable — using OpenGL" could appear by mistake** after Picture in Picture. If Lumora ever does switch to OpenGL, the reason is now saved in `~/Library/Application Support/Lumora/Logs/renderer-fallback.log`.
- **Converter:** Cancel shows "Cancelled." and removes the half-written file; converting the same file again no longer fails.
- **Up next** no longer starts the next video after you press Stop or seek back.
- **Continue Watching** is back to the simple list rows.

### Privacy and security
- **Crash reports** remove more personal detail before you send them: full file and folder names (including names with dots or spaces), server names and IP addresses.
- **Releases** can only be signed and published from reviewed code on `main`, and a release is published only once both the app and the update feed are uploaded.
- New `SECURITY.md`: report security problems privately from the repository's Security tab.

### Other
- Lumora now states its real minimum system: macOS 27.
- The recent-errors log is written at most once a second, saving work while a broken stream reports errors.

### Install / update
Existing installs are offered this update automatically (Lumora → Check for Updates…).
New installs: download `Lumora-0.14.1.dmg` and drag Lumora into Applications. First launch only: **System Settings → Privacy & Security → Open Anyway** (not notarized yet).
