## Lumora 0.14.2 — smaller download

### Changed
- **Smaller app:** Lumora's built-in video engine now includes only the parts it uses. The app is 48 MB instead of 52 MB, and the download is about 21 MB instead of 23 MB. Every video, audio and subtitle format that played before still plays, and the equalizer, deinterlacing, playback speed, rotation and thumbnails work as before.

### Other
- Builds now check the versions of the bundled helper libraries, so each release is built from a known set.

### Install / update
Existing installs are offered this update automatically (Lumora → Check for Updates…).
New installs: download `Lumora-0.14.2.dmg` and drag Lumora into Applications. First launch only: **System Settings → Privacy & Security → Open Anyway** (not notarized yet).
