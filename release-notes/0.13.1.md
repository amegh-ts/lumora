## Lumora 0.13.1 — crash fix

### Fixed
- **Lumora could quit unexpectedly while playing.** It happened when macOS asked for the video's picture to show in Control Centre or on the lock screen (Now Playing). The picture is now handed over safely.
- **Media keys and AirPods controls** use the same safeguard, so they can't cause the same crash.
- **Crash reports** name the real culprit in their title instead of an internal Swift function.

### Install / update
Existing installs are offered this update automatically (Lumora → Check for Updates…).
New installs: download `Lumora-0.13.1.dmg` and drag Lumora into Applications. First launch only: **System Settings → Privacy & Security → Open Anyway** (not notarized yet).
